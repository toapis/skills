# ToAPIs Skills

Agent Skills for [ToAPIs](https://toapis.com).

| Skill | Description |
|---|---|
| [`toapis-media`](skills/toapis-media/SKILL.md) | Generate and edit images and videos with ToAPIs models through the ToAPIs MCP server |

The skills call the ToAPIs MCP server for every business action. Connect it first: see [connect.md](skills/toapis-media/references/connect.md).

## Development

The file helper script needs Node 20 or newer and has no dependencies.

```bash
npm test
```
